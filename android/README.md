# Android native client

Native Kotlin + Jetpack Compose application. This is the initial app shell, not a feature-complete client yet.

## Build
Open the `android/` directory in Android Studio with JDK 17 and Android SDK 35 installed, then sync Gradle and run the `app` configuration.

The initial shell contains native bottom navigation and MeetCloud visual tokens. API networking, authentication, map, persistence and production localization are intentionally not claimed as implemented yet.
