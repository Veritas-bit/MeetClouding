# **App Name**: LinguaLink

## Core Features:

- Text Messaging: Real-time text messaging with threaded conversations.
- User Authentication: User authentication via magic link.
- Live Translation: Real-time translation tool powered by LLM.
- Content Recognition: Automatic detection of URLs and @mentions.
- Push Notifications: Notifications upon new messages

## Style Guidelines:

- Primary color: Soft blue (#64B5F6), inspired by feelings of trust and easy communication.
- Background color: Very light blue (#F0F8FF), providing a calm backdrop.
- Accent color: Subtle violet (#9575CD) for interactive elements.
- Font pairing: 'Inter' (sans-serif) for both headlines and body text, prioritizing legibility.
- Simple, modern icons to represent message status (sent, delivered, read) and other common actions.
- Clean, minimalist layout with clear visual hierarchy for easy navigation.
- Subtle animations for message transitions and user interactions.
